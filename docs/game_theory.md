# Game Theory Model

## Players

Each Wi-Fi user is considered a player.

Example:

- User 1
- User 2
- User 3
- User 4

## Resource

The limited resource is the available Wi-Fi bandwidth.

Example:

Total bandwidth = 40 Mbps

## Strategy

Each player chooses the amount of bandwidth they want to use.

For example:

User 1 → 10 Mbps

User 2 → 15 Mbps

User 3 → 20 Mbps

## Utility

The utility function represents the benefit obtained by a user from receiving bandwidth while considering congestion.

Conceptually:

Utility = Bandwidth Benefit - Congestion Cost

## Congestion

When many users consume bandwidth simultaneously, network congestion increases.

Therefore:

More bandwidth usage
→ More congestion
→ Higher congestion cost

## Nash Equilibrium

The system searches for a situation where no individual player can improve their utility by changing their bandwidth strategy while considering the strategies of other users.

## Fairness

Jain's Fairness Index is used to measure how fairly bandwidth is distributed.

The value ranges from:

0 → Very unfair

1 → Perfect fairness
